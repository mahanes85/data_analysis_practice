## 📖 About

This repository contains exercises, assignments, and projects developed throughout a Data Analysis course. Each project is organized separately to keep code, datasets, Jupyter Notebooks, and related files structured and easily accessible.

The main goal is to strengthen Python programming skills, understand data analysis concepts, and gain practical experience working with real-world data.

## 📂 Repository Contents

This repository includes practical exercises and projects covering different topics in data analysis. Each project is stored in its own directory and may contain Python scripts, Jupyter Notebooks, datasets, and other related resources.

New exercises and projects will be added as I continue learning.

## 🛠️ Technologies

The tools and libraries used throughout this repository include:

- **Python 3** – Main programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computing
- **Matplotlib** – Data visualization
- **Jupyter Notebook** – Interactive coding and analysis

Additional libraries may be introduced in future projects.

## 🚀 Getting Started

### Prerequisites

- Python 3
- pip
- Jupyter Notebook (if required)

### Install Dependencies

Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

To install Jupyter Notebook:

```bash
pip install notebook
```

### Run a Python Script

Navigate to the desired project directory and run the Python file:

```bash
python script_name.py
```

### Run a Jupyter Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open the desired `.ipynb` file.
